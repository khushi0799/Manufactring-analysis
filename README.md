📊 Manufacturing Analysis Dashboard

Description:

This project focuses on analyzing and visualizing key manufacturing performance metrics using an interactive dashboard. It provides insights into production efficiency, wastage, work orders, buyer contribution, departmental performance, and customer-wise output.

The dashboard helps stakeholders track total manufactured quantity, production trends, wastage percentage, operational output, and overall production value. Interactive filters allow users to drill down by buyer, department, month, and process, enabling data-driven decision-making.

Key Highlights:

Month-wise production trend analysis

Operation-wise quantity comparison

Buyer and customer-wise quantity distribution

Department-wise processed, pressed, and rejected quantities

Interactive slicers for dynamic analysis

Tools & Technologies:
Excel, Power BI, SQL, Tableau, Data Visualization, Data Analysis
